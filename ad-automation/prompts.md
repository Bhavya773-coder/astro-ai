# astroai4u.com Ad Prompts Reference

This file contains highly detailed, conversion-focused prompts for generating paid-social advertisements for `astroai4u.com` using AI image models such as Gemini, Imagen, Midjourney, Ideogram, or other commercial image generators. Every prompt is self-contained and intentionally written as an **advertisement**, not as generic astrology artwork. The purpose of each creative is to communicate one specific product benefit, show the real AstroAI4U experience, establish how the platform differs from ordinary horoscope apps, and guide the viewer toward a clear action.

---

## Brand Aesthetic Standards
* **Domain Name:** `astroai4u.com` — always lowercase, never spaced, never misspelled.
* **Core Positioning:** A personal AI astrology platform that combines conversational guidance, birth-chart context, and multiple self-discovery tools in one connected experience.
* **Flagship Feature:** **My Oracle**, an interactive AI astrologer that allows users to ask personal questions instead of only reading static horoscope text.
* **Background:** Deep near-black cosmic gradient (`#050308` fading into `#0B0614`).
* **Primary Gradient:** Electric violet (`#7C3AED`) to vivid fuchsia (`#D946EF`).
* **Astrology Accent:** Solar gold (`#FACC15`) for chart lines, zodiac details, and premium highlights.
* **AI Accent:** Cyan (`#22D3EE`) for scanning beams, analysis nodes, live indicators, and intelligent-system details.
* **Interface Style:** Premium glassmorphism, dark mobile UI, translucent panels, subtle blur, thin luminous borders, realistic product screens, modern typography, and generous spacing.
* **Advertising Principle:** The benefit and product interaction must be the hero. Stars, moons, zodiac symbols, tarot cards, nebulae, and sacred geometry are supporting elements only.
* **Required Hierarchy:** One strong headline, one short supporting line, one visible product interaction or result, one CTA button, and the domain.
* **Typography:** Use bold, clean, modern sans-serif typography. Reserve clean areas for exact copy. For final campaigns, overlay text manually in Figma, Canva, Photoshop, or the advertising platform because image models may distort words.
* **Avoid:** Generic floating zodiac wheels, isolated mystical objects, excessive nebulae, cheap occult styling, horror aesthetics, fake ratings, fabricated testimonials, unsupported accuracy percentages, guaranteed predictions, long paragraphs, unreadable UI, random decorative symbols, watermarks, and garbled text.
