# AstroAI4U Stationery Kit

Original reusable SVG assets derived from the visual direction of the supplied AstroAI4U screens. Includes torn paper, translucent washi tape, hand-drawn stars, brush underline, and a seamless dark star field, plus an Expo component and a ready-to-paste Antigravity brief.

All SVG colors are editable. These assets contain no raster image dependencies and scale cleanly. Keep live content inside the safe-area rules in `ANTIGRAVITY_PROMPT.md`.

Files: `assets/*.svg`, `src/HandmadeCard.tsx`, `ANTIGRAVITY_PROMPT.md`.
